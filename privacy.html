Privacy Policy

Last updated: 24 November 2026

This policy covers the website fablemare.com and the Fablemare Uploader, an internal tool that the Fablemare channel uses to publish videos to its own YouTube channel. Fablemare is run by Akshay Suresh, Abu Dhabi, United Arab Emirates.

The website

fablemare.com is a static website. It sets no cookies, runs no analytics or advertising scripts, and collects no personal information. Our interactive stories remember which endings you have found using your browser's local storage; that information stays on your device and is never sent to us. The hosting provider may keep standard server logs (such as IP address and browser type) for security and operation.

Fablemare Uploader and YouTube API Services

The Fablemare Uploader uses YouTube API Services. It is used only by the Fablemare channel owner, to manage the Fablemare YouTube channel. It is not offered to the public.

When the channel owner signs in with Google, the tool requests access to:

  • upload videos and set their titles, descriptions, tags, thumbnails, schedules and playlists (YouTube Data API);
  • read the channel's own video list and details (YouTube Data API);
  • read the channel's own performance reports, such as views and watch time (YouTube Analytics API).

This data is used only to publish Fablemare videos and to review how they perform. It is not sold, not shared with third parties, not used for advertising, and not used to train AI models. The tool does not access any other user's data.

The sign-in token is stored in encrypted, access-restricted storage controlled by the channel owner. Reports are kept only as long as needed to plan future videos. Data received from Google APIs is handled in line with the Google API Services User Data Policy, including the Limited Use requirements.

By using a product that uses YouTube API Services, you are also subject to the Google Privacy Policy and the YouTube Terms of Service.

Revoking access

Access can be removed at any time from your Google Account security settings: security.google.com/settings/security/permissions. To ask for any stored data to be deleted, email us and it will be deleted within 7 days.

Children

Fablemare content is not made for children, and the website does not knowingly collect information from anyone.

Changes

If this policy changes, the new version will be posted on this page with a new date.
